SwimTracker

Pull a swimmer's times from the USA Swimming Data Hub after each meet.

1. Install the button (once)

On a computer: drag this to your bookmarks bar → SwimTracker pull

On iPhone (Safari):

  1. Tap Copy code below.
  2. Bookmark any page (Share → Add Bookmark), name it SwimTracker pull.
  3. Open Bookmarks → Edit → tap the new bookmark, replace its address with the copied code, Done.

Summer team (SwimTopia): capture button

For SwimTopia (Tidal Waves) or any page that shows times in a table. It reads the tables on the page you are looking at (no requests of its own) and adds them to SwimTracker.

On a computer: drag this to your bookmarks bar → SwimTracker capture

On iPhone: same steps as above with this code, named SwimTracker capture.

Use it on the page that lists the swimmer's times (athlete times or meet results), signed in.

2. After a meet

  1. Open the USA Swimming Data Hub, sign in with your USA Swimming account (free; athlete search needs a login), and open the swimmer's page.
  2. Tap the SwimTracker pull bookmark (iPhone: type "SwimTracker" in the address bar and pick the bookmark).
  3. When it finishes, it opens SwimTracker and adds the new swims, listing any new best times.

It runs in your own browser, reads only that swimmer's times, and pauses between requests. The data travels in the part of the link after #, which browsers never send to a server: it goes only into this browser's storage.

If something goes wrong, the button shows a panel instead: tap Add to SwimTracker, or Save file and use Import on the dashboard.

Other devices

Each browser keeps its own copy. Run the button there too, or use Export on one device and Import on the other.
